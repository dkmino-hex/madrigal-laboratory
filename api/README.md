# HTTP-контракт

Актуальный публичный контракт всех сервисов: [contracts/gateway.openapi.json](../contracts/gateway.openapi.json). Gateway отдаёт его также по `/openapi.json`.

`openapi.yaml` сохранён как историческая схема исходной ветки Analysis. Для генерации клиента и проверки текущей интеграции используется общий контракт.
