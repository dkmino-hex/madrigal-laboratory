Frontend обращается только к публичному Gateway через `shared/api`. Большие координаты передаются десятичными строками, арифметика выполняется через BigInt. Ревизии и исторические сборки неизменяемы. Ошибка API не переключает приложение на моки.

Тесты покрывают модель данных, компоненты и браузерные сценарии. Порядок запуска, ограничения демонстрационных данных и требования к реальной интеграции находятся в [README](../../README.md), [verification.md](verification.md) и [integration.md](integration.md).
