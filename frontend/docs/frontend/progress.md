# Состояние frontend

На 13 октября 2026 года экраны FE-01–FE-11 доступны для командного просмотра в mock-режиме. Клиент использует временные нормализованные DTO. Реальная интеграция остаётся отдельным этапом: нужно согласовать публичный OpenAPI, заполнить mapping и проверить приложение с Gateway и приёмочным корпусом.

| Задача | Реализация                                                                                         | Что проверить при подключении backend                       |
| ------ | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| FE-01  | Маршруты, общий API-клиент, загрузка и ошибки, темы, точные координаты и время                     | BASE-02, wire adapters, обработка ошибок Gateway            |
| FE-02  | Проекты, импорт PCAP/PCAPNG/ZIP, IMPORTING, экспорт и скачивание готовых файлов                    | Workspace/Capture, независимый ZIP, хеши                    |
| FE-03  | Captures, TCP-сессии, направления, роли, дефекты и страницы версий assembly                        | Capture sessions/assemblies                                 |
| FE-04  | Окна HEX/ASCII, выделение мышью и клавиатурой, поиск, большие offsets, gap/conflict/truncation     | Capture bytes/search, реальные большие записи               |
| FE-05  | CSV, исходное и скорректированное время, ручные связи, уверенность и редактирование основания      | Workspace CSV/evidence                                      |
| FE-06  | Два диапазона, различия, неизвестные данные и хвосты, отдельные модели и ревизии, извлечённые поля | Analysis preview/results                                    |
| FE-07  | JSON-редактор, формы, точное сохранение ревизий и расширений, preview и ошибки                     | Полная модель AN-03 и серверная валидация                   |
| FE-08  | Наблюдения и гипотезы, статусы, подтверждения, контрпримеры и ссылки                               | Workspace hypotheses/evidence                               |
| FE-09  | Точные входы корпуса, версии настроек, история, сводки, фильтры и сравнение запусков               | Analysis jobs/runs/results                                  |
| FE-10  | Поле/контрпример → закреплённая сборка, исходные кадры и выделение байтов                          | Capture SourceMap/packets, реальные большие кадры           |
| FE-11  | Jobs трёх владельцев, известный/неизвестный/нулевой total, отмена, повторное чтение, отчёты        | Настоящий Gateway, перезапуски сервисов, скачивание отчётов |

Длинные списки загружаются по страницам; выбранные модели и запуски перечитываются по ID. Черновики Settings, Actions, редактора и нового корпуса защищены при уходе. Ответы сохранения проверяются по проекту и идентификаторам. Исторические источники не переназначаются на новые версии.

Подготовленный demo-корпус сохраняется отдельно от реальных данных. Его ограничения перечислены в [README](../../README.md). Успешные mock-тесты не подтверждают совместимость с настоящим API, произвольными PCAP, полной схемой AN-03 или независимым архивом Workspace. Критерий FE-11 о подключении ключевых экранов к реальному API остаётся открытым.

В backend-ветке `backend/analysis-workspace` опубликован `api/openapi.yaml`. Следующий шаг — согласовать его с [картой клиента](integration.md) и [вопросами по контракту](api-contract-gaps.md), подключить wire adapters и выполнить API E2E. Затем с backend-командой проверить перенос проекта, перезапуски и общий Linux-профиль.
