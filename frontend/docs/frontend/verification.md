## Покрытие

Модель данных: точные decimal/BigInt координаты, наносекундное время, неизвестные байты и конфликты, SourceMap и контекст проекта, неизменяемые версии, JSON с расширениями, сводки частичных/исторических запусков.

Компоненты: HEX и выделение, исходные пакеты и виртуализация, редактор, результаты и сводки, общий статус заданий, доступные диалоги, пагинация.

Браузер: проект → импорт → сессия/assembly → диапазон → CSV/связь → сравнение → гипотеза → ревизия/preview → проверка корпуса → контрпример → исходные кадры → новая ревизия/запуск → сравнение сводок → старая ссылка после reload. Дополнительно проверяются ошибки, отмена, импорт/экспорт demo-снимка, разные проекты и режимы.

Логи, HTML-отчёты, screenshots и metrics создаются локально и исключены из Git. Повторный запуск mock-suite выполняется без retries. Для mock, production, API и browsers используются отдельные outputDir и HTML reports; параллельные процессы с одинаковым каталогом отчёта запускать нельзя.

## Реальная интеграция

Mapping публичного API пока не заполнен. API E2E требует `MADRIGAL_GATEWAY_URL`, согласованный OpenAPI и идентификаторы реального проекта/запуска/источника. При отсутствии окружения preflight завершается ненулевым кодом. Успешный mock-suite не заменяет эту проверку.

Произвольные PCAP/PCAPNG, полная модель AN-03, независимый ZIP/хеши, настоящий CLI, перезапуск сервисов и Linux-профиль 4 vCPU/8 ГиБ требуют общей проверки с backend. Состояние функций и задачи передачи перечислены в [progress.md](progress.md) и [integration.md](integration.md).
