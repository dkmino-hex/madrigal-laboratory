# Исправления после визуальной проверки

Проверка замечаний выполнена 13–14 октября 2026 года. Для каждого из 18 пунктов исходного документа сопоставлены снимки экрана, код и поведение приложения. Изменения общих компонентов применяются на всех страницах, которые их используют. Дополнительные проверки охватывают ввод, выбор параметров, сохранение, переходы между страницами и восстановление чтения данных.

В этой рабочей копии доступен frontend с демонстрационным корпусом. Карта реального Gateway остаётся пустой, поэтому результаты ниже подтверждают frontend и демо-контракт. Согласование и проверка настоящих сервисов описаны в [integration.md](integration.md).

## Дополнительные исправления

- Общая валидация различает пустое значение, неверный формат, отрицательное или дробное число, пустой диапазон и выход за границы. Ведущие нули и внешние пробелы чисел нормализуются; большие координаты остаются точными.
- Проекты, интерпретации и исследовательские записи не принимают формулировки из пробелов и непечатные управляющие символы. Применяются ограничения длины и пояснения у полей.
- Пустые файлы и неверные расширения отклоняются до передачи. Настройки времени одинаково проверяются в настройках проекта и импорте журнала.
- Даты проверяются календарно, учитывают часовой пояс и наносекунды; начало не может быть позже конца. Выход скорректированного времени за календарные границы не обрушает журнал. CSV сообщает конкретную строку с такой ошибкой.
- В распознанном формате схемы проверяются размер сообщения, порядок байтов, направление, имена и идентификаторы полей, размещение uint32, ссылки правил на поля и максимум uint32. Очистка размера не заменяет его скрытым null. Переименование поля в форме обновляет связанные правила. Неизвестные расширения JSON сохраняются без округления чисел.
- Preview показывает предел 4096 байтов у поля длины. Пустые и выходящие за границы диапазоны не используются для сохранения связи или разбора.
- Устаревшие ревизии и версии настроек из ссылок требуют корректного выбора. Уже добавленную сборку нельзя незаметно добавить повторно: кнопка и пояснение отражают это состояние.
- Старые результаты поиска HEX/ASCII очищаются при изменении образца или режима, чтобы они не выглядели результатом нового запроса.
- Ссылки на источники полей в сравнении получили отдельные контуры и промежуток. Карточка JSON-редактора не растягивается пустым блоком до высоты боковых настроек.
- Отложенный поиск приостанавливается, пока пользователь решает, уходить ли со страницы с черновиком. Это исправляет гонку, обнаруженную в WebKit: поиск больше не закрывает подтверждение ухода. После решения остаться поиск продолжается; после ухода таймер старого экрана удаляется.
- Обязательное название из одних невидимых Unicode-символов считается пустым. Ошибка при недоступном буфере одинакова у ссылки на источник и кнопок копирования HEX/ASCII; пользователю не показывается внутренний TypeError.
