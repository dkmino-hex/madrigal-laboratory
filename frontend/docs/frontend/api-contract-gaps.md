# Пробелы контрактов и внешние зависимости

Frontend ещё не проверен с реальными сервисами. В ветке `backend/analysis-workspace` есть OpenAPI/Gateway/Analysis, в `backend/capture` — Workspace/Capture и приёмочный корпус. Требуется согласовать публичные операции, CSV/AN-03/ZIP manifest, затем проверить mapping и адаптеры на этих версиях. Временные модели frontend не являются стандартом других разработчиков.

Карта `src/shared/api/contracts/gateway-mapping.json` пуста. `registry.ts` содержит 36 внутренних операций UI; их количество не доказывает соответствия перечню публичных операций D1. В API неизвестная операция возвращает `CONTRACT_PENDING` до fetch. В mock используются изолированные пути `/__madrigal_mock/v1/<operation>` и тот же client/transport. Для каждой операции path/operationId — «не согласован»; полная карта в `integration.md`.

## Что именно ограничено в demo

Подготовленный Analysis поддерживает A→B первого поколения. Precision fixture предназначен только для HEX/точности/нагрузки; другая ось/область схемы не получает готовые результаты по умолчанию. Ограничение отдельно проверено через общий client/MSW.

- PCAP/PCAPNG — маленькие синтетические golden-fixtures, а не результат TCP-восстановления. Принимаются только эти точные файлы до 64 КиБ; дубликат проверяется по содержимому в MSW, а не имени. Произвольный capture получает DEMO_LIMITATION. Настоящий File проходит FormData без чтения целиком в React; авторитетный большой hash вычисляет backend.
- CSV demo: UTF-8, `timestamp,name,type,parameters`, comma delimiter, явный UTC offset или UI timezone, ns correction, ошибки строк/partial. Сложное quoting/escaping не поддерживается; полный формат ожидается от Workspace. Малый demo CSV читается только в MSW.
- Разбор demo: fixed framing 4 bytes, uint32 LE, первое поле offset 0, порог 30/60. Схема сохраняется точно с unknown extensions, но произвольные framing/endian/types/rules получают явное DEMO_LIMITATION; browser не исполняет пользовательский код. Создание новой assembly тоже явно ограничено до настоящего Capture действия.
- ZIP demo восстанавливает снимок внутри того же browser demo-state по marker в комментарии prepared ZIP. Архив не распаковывается приложением; это не независимый перенос на другую машину, не hash/security проверка и не INT-03. Размер/жизненный цикл настоящего snapshot должен определить backend. Markdown содержит выбранный run и снимок, помечен демонстрационным.
- Hypothesis `open/supported/refuted`, evidence `tentative/confirmed` и `support/counterexample` — provisional enum WS-07. PASS не повышает гипотезу автоматически.
- 1000 сессий и точные большие offsets создаются лениво; не представлены реальные 100 МиБ/250000 пакетов/100000 сообщений. Проверка Linux 4 vCPU/8 ГиБ и общесистемная память/производительность не выполнены.

Реальный smoke не удалось начать: preflight завершился ошибкой отсутствующего MADRIGAL_GATEWAY_URL, а api:generate/check — отсутствующего BASE-02 OpenAPI. До появления этих данных доступны все локальные frontend-проверки; автоматический переход на fixture при API-ошибке запрещён и проверен.
